# Welcome to your my project

## Project info

**URL**: https://stay-fit-pro.netlify.app/


Stay Fit Pro 🏋️‍♂️

Stay Fit Pro is a modern fitness web application that helps users maintain a healthy lifestyle by discovering exercises, tracking fitness routines, and exploring nutritional information. The application integrates external APIs to provide real-time exercise and food data through an intuitive and responsive interface.

🚀 Features
💪 Browse a collection of exercises with images/GIFs
🔍 Search exercises by name, body part, or target muscle
📋 View detailed exercise instructions and muscle information
🍎 Explore nutritional information using a Food API
📱 Fully responsive design for desktop, tablet, and mobile
⚡ Fast and interactive user experience
🎨 Clean and modern UI built with Tailwind CSS

🛠️ Tech Stack
Frontend: React.js, TypeScript
Styling: Tailwind CSS
APIs:
Exercise API
Food/Nutrition API
Build Tool: Vite

📸 Key Modules
Home Page – Attractive landing page with featured exercises.
Exercise Explorer – Browse and search exercises by category.
Exercise Details – View GIFs, instructions, target muscles, and equipment.
Nutrition Section – Search foods and view calorie and nutrient information.
Responsive Layout – Optimized for all screen sizes.
